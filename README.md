# QQ 群伙伴 1.6.1

腾讯官方 QQ 群机器人收到群内 @ 文字或图片后，由 Cindy 模型或指定伙伴回答，再关联原消息回复原群。最多 4 个机器人，凭证、连接与路由独立，最低支持 Cindy 0.1.124。

## 一次性问答与连续会话

- 普通 @Bot 问题默认只回答这一条，插件不持久保存提问正文、答案或自动建立问答历史。
- @Bot /talk：立即回群确认开启连续会话，不调用模型生成这条确认。
- @Bot /talk 问题：开启或继续会话，并回答该问题。
- 开启后，这个人在同一个群里的普通 @ 也继续会话；其他群友仍是一次性问答。
- 连续 2 小时没有新的有效消息或确认答复后，会话结束。此后普通 @ 回到一次性问答，下次 /talk 开启新会话。
- 重复投递、无效附件与排队满而未接受的消息，不延长会话期限。

会话按机器人、AppID、环境、群、发言人和伙伴匹配，最多保留 80 个活跃会话、每个最多 8 轮文字缓存。消息和答复都会更新活动时间，过期缓存会清理。

未选择伙伴时，一次性问题各自新建 Cindy 对话，/talk 为该人创建并复用独立的 Cindy 对话，使用系统辅助模型。恢复连续对话时从宿主读取最新任务 revision 后再发送，重启后仍可在有效期内续聊。选择伙伴时，问题进入伙伴现有的标准对话；插件只注入当前发言人的 /talk 缓存。伙伴的原生模型历史并非按 QQ 发言人强隔离，建议选择专门的公开群答疑伙伴。

连续会话对应的 Cindy 对话被删除或归档时，普通续聊会收到重新 /talk 的提示，该问题不会在其他任务重发；明确发送 /talk 则用新的会话标识重新开启。读取任务超时不视为任务已删除，投递回执不明确时也不自动重试。

“不记录”指插件不保存普通问答正文。为防重复回复，插件仍保存请求编号和收发状态；Cindy 自身的对话及媒体按宿主规则保留。升级时清理 1.3.0 及以前的自动问答缓存，保留机器人账号、凭证、连接配置和防重复状态，不把旧缓存自动当成 /talk 会话。

## 配置与管理

1. 在 https://q.qq.com/ 创建官方机器人，并按平台要求开通群聊事件、回复和入群权限。
2. 在插件内添加机器人，填写 AppID 与 AppSecret。凭证由 Cindy 保险库加密保存，不进入聊天、/kv 或状态文件。
3. 默认不选伙伴；也可用头像和名字共用的单选卡切换伙伴，切换立即保存。
4. 完整账号与凭证保存后自动连接，默认接收该机器人已加入的所有群内 @。普通群消息、私聊和机器人自己发的消息不转交。

首页分别显示每个机器人的运行、暂停与连接状态。启动自检与连接失败在首页红色提醒；“重新自检”只检查、恢复连接，不重放问答。缺凭证或权限时保留准确诊断，处理后用“保存并连接”恢复。主动暂停会保留，连接进程中断时自动探测并退避恢复。

删除按钮位于账号标题旁，可以删到零个机器人。删除先停止连接，再清理对应凭证、请求与连续会话缓存；晚到的投递、图片、任务创建或回群结果不会恢复已清理记录。其他机器人及 Cindy 原对话保留。设置页也可结束该机器人的全部连续会话并清理缓存。

## 图片与回复边界

支持 PNG/JPEG/WebP，每条最多 4 张、每张 5 MiB，关联原群回复最多 1800 字符的文字。图片以真实附件提供，不作为文字 URL；看图需要模型支持。每个机器人同时处理 1 条、最多排队 12 条。

QQ 发言人标识是平台 openid，不是可反查的 QQ 号码。群成员内容是外部资料，不授予文件、账号或执行权限。回复只能由接收该请求的 Cindy 会话调用 reply_to_qq，并经过请求编号与会话 ID 校验。发送结果不确定或宿主重启后不自动重发；普通问答正文不落盘，尚未派发的旧队列在重启时取消。

## 主人主动群发

保留已安装 1.5.0 的主动消息功能。主人在 Cindy 明确要求发送通知时，先 get_status 核对机器人编号及对应的群 OpenID，再调用 send_group_message，填写 bot_id、group_openid、text 和唯一 request_key。群 OpenID 不是 QQ 数字群号，不能跨机器人复用。文字最多 1800 字符，凭证与主动发送权限以 QQ 平台实际授权为准。

主动发送返回实际机器人、AppID、环境、群及消息回执。同一 request_key 七天内防重复；结果不确定时检查原群，不换键重发。群问答来源的会话不能主动群发或读取主动回执。主动发送不更改 /talk 上下文。这里的七天防重复记录与 TODO 中的七天查询任务删除是不同功能。

含 tasks 映射的并发开发版状态在处理前备份到 backups/，保留旧 QQ 会话的权限限制；核心 /talk 状态保留 schema 3，不因升级或重启转换为旧自动追问模式。

## 新会话权限

在 Cindy「插件 → QQ 群伙伴 → 模型与任务 → 动手权限」选择「完全访问」。此后新建的 QQ 成员会话沿用这个设置；也可随时改为「询问」或「自动审批」。未选择时使用 Cindy 的默认权限「询问」，插件不会自行提升权限。

设置只决定后续新会话；已有会话继续使用其当前权限，可在会话输入框旁单独调整。每群模型仍使用群配置中已选择的完整模型组合。
